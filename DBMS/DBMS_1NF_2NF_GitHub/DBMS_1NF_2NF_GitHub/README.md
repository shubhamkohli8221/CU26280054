# DBMS Lab: 1NF and 2NF Using MySQL

This repository contains the SQL programs and practice questions from the supplied **DBMS Lab Sheet: 1NF and 2NF Using MySQL**.

## Repository structure

```text
DBMS_1NF_2NF_GitHub/
├── README.md
├── practice_questions.md
└── sql/
    └── normalization_lab_1nf_2nf.sql
```

## Requirements

- MySQL 8.0
- MySQL Workbench, MySQL Shell, or another MySQL client

## How to run

1. Open MySQL Workbench or MySQL Shell.
2. Open `sql/normalization_lab_1nf_2nf.sql`.
3. Execute the script from top to bottom.
4. Review the query results after each section.
5. Use `practice_questions.md` to complete the lab exercises.

## Topics covered

- Unnormalized Form (UNF)
- First Normal Form (1NF)
- Composite primary keys
- Partial functional dependencies
- Second Normal Form (2NF)
- Primary keys and foreign keys
- SQL `JOIN`, `INSERT`, `UPDATE`, and `DELETE`
