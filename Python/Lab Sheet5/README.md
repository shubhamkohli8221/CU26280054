# Lab Sheet 05 — Python Programming Lab: Tuple Operations

This folder contains 30 separate Python programs for COER University MCA I Semester Lab Sheet 05.

## How to run
1. Open this folder in VS Code.
2. Open any `Qxx_...py` file.
3. Run it using the Run button or the terminal:
   ```bash
   python Q01_tuple_creation.py
   ```
4. For programs that ask for input, enter a suitable value when prompted.
