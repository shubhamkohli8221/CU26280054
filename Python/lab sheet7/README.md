# MCA Python Lab Sheet 07 — File Handling

This folder contains Python solutions for all 30 questions in the uploaded lab sheet:
text files (1–20) and CSV files (21–30).

## Requirements
- Python 3.x
- No third-party packages are required.

## How to run
Open this folder in VS Code. In the terminal, run a program, for example:

```bash
python 01_write_file.py
python 02_read_entire_file.py
```

Run each program from this folder so its relative input/output file names work.
Some programs require files created by other programs:
- `sample.txt`: created by `01_write_file.py`
- `numbers.txt`: create this yourself with numbers separated by spaces or new lines
- `file1.txt` and `file2.txt`: create these for program 20
- `students.csv`: created by `21_create_csv.py`
- `students_extra.csv`: optional second CSV for program 30

Each program includes comments and basic error handling. Programs that modify a file may change its contents, so keep a backup if needed.
