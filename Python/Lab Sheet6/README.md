# Lab Sheet 06 — Python Programming Lab: Set Operations

This folder contains 30 separate Python programs based on the COER University MCA I Semester Lab Sheet 06.

## How to run
1. Open this folder in VS Code.
2. Open any `Qxx_...py` file.
3. Run it with the Run button or use the terminal, for example:
   ```bash
   python Q01_set_creation.py
   ```
4. Enter values when a program asks for user input.

## Notes
- Sets are unordered, so the displayed order of elements may vary.
- Set elements must be hashable.
- Q27 includes a correct sorted-string check because comparing sets alone can miss repeated-letter differences.
- Test the programs with different inputs before submission.
